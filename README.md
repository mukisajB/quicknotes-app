# QuickNotes App

QuickNotes is a simple note-taking web app built with HTML, CSS, and JavaScript. It lets you add, delete, search, and categorize notes, with persistence via localStorage.

## Features
- Add notes with categories (Personal, Work, Study)
- Delete notes
- Search notes by text
- Validation for empty or too-long notes
- Notes saved in localStorage
- Responsive design with Flexbox and media queries

## Run locally
1. Clone the repo: `git clone https://github.com/mukisajB/quicknotes-app`
2. Open `index.html` in your browser.

## What I learned
- How to structure semantic HTML with forms and sections
- Using Flexbox for layout and responsiveness
- Creating dynamic lists with `createElement` and `textContent`
- Persisting data with localStorage
